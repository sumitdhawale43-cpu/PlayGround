# PlayGround

**BLADE ARENA** is a fast, browser-based 2D fighting game rendered on Canvas with no external art or audio assets. Pick AKIRA / FROSTFANG or RAZE / CRIMSON RONIN, choose one of three arenas, and fight a CPU opponent in a best-of-three match.

- **Move / jump:** `A` `D` / `W`, or `←` `→` / `↑`
- **Punch / kick / block:** `J` / `K` / `L`
- **Special (50 energy):** `Space`
- **Pause:** `Esc` or `P`
- On touch devices, use the on-screen direction pad and action buttons.

Open `index.html` through any static web server (for example `npx serve .`) or run `./start.sh` when the OMGithub runtime is available.
